# TC-03: Оформление заказа с пустым обязательным полем Zip/Postal Code.

* **ID:** TC-03
* **Модуль / Раздел:** Каталог -> Корзина -> Оформление заказа (Checkout)
* **Тип теста:** Негативный (Negative)
* **Приоритет (Priority):** High
* **Окружение:** Chrome 157, macOS 26.6.2
* **Статус:** Pass

---

### Предусловия (Preconditions)
1. Открыт браузер Chrome.
2. Пользователь авторизован под учетной записью `standard_user` и находится на странице каталога.
3. Корзина пуста (на иконке корзины отсутствует счетчик товаров).

---

### Шаги выполнения (Test Steps)

| № | Действие (Action) | Тестовые данные (Test Data) | Ожидаемый результат (Expected Result) |
| :--- | :--- | :--- | :--- |
| 1 | Нажать кнопку «Add to cart» в карточке товара `Sauce Labs Bike Light` | — | Текст кнопки меняется с «Add to cart» на «Remove», рамка и текст становятся красными. На иконке корзины в правом верхнем углу появляется красный счетчик со значением `1`. |
| 2 | Нажать на иконку корзины в правом верхнем углу страницы | — | Открывается страница корзины (`https://www.saucedemo.com/cart.html`). В списке отображается товар `Sauce Labs Bike Light` (количество: `1`, цена: `$9.99`). |
| 3 | Нажать кнопку «Checkout» | — | Открывается первый шаг оформления заказа `Checkout: Your Information` (`https://www.saucedemo.com/checkout-step-one.html`). |
| 4 | Заполнить поля `First Name` и `Last Name` валидными данными, оставив Zip/Postal Code пустым | **First Name:** `Denis`<br>**Last Name:** `Denisov`<br>**Zip/Postal Code:** — (оставить пустым) | Введенные значения `First Name` и `Last Name` корректно отображаются в соответствующих полях формы, поле Zip/Postal Code остается пустым |
| 5 | Нажать кнопку «Continue» | — | Переход на следующий шаг не происходит. Поля формы подчеркиваются красной линией, справа от них появляются красные иконки с крестиком. Под формой появляется красный блок с текстом ошибки: `Error: Postal Code is required` |

---

### Постусловия (Postconditions)
1. Нажать кнопку «Cancel»
2. Удалить товар, нажав кнопку Remove рядом с товаром. 
3. Нажать кнопку «Continue Shopping» для возврата на страницу каталога.
